# Payflow System

## About the project

Payflow System is a backend project inspired by digital banking platforms like Revolut.

The main goal of this project is learning. I wanted to build a real-world backend application while using as much as possible of the technology stack required by the Revolut Software Engineer position.

The idea was to explore topics that are common in production systems, such as containerization, Kubernetes, monitoring, caching, database migrations, testing, and cloud-ready development.

## Tech Stack used in the project

### Backend
- Java 25
- Spring Boot 4

### Database
- PostgreSQL
- jOOQ
- Flyway

### Cache
- Redis

### Testing
- Spock
- k6 (Load Testing)

### Monitoring
- Prometheus
- Grafana
- New Relic

### DevOps
- Docker
- Docker Compose
- Kubernetes
